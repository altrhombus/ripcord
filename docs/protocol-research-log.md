# Protocol research log

Clean-room provenance record for Ripcord's PlayStation and Xbox protocol backends. Every
external reference consulted while researching wire formats/handshakes/HID reports is logged
here before any spec document is written from it. See the plan's "Clean-room methodology"
section for the full process this log supports.

Columns: date consulted, reference, what it informed, which spec doc section it fed.

**Redaction policy.** Values tied to a particular console, account, or session are redacted in this
published copy and replaced with stable placeholders — `<registkey-wire>` / `<registkey-hex>` /
`<registkey-dec>` (the three encodings of one registration key), `<ps4-registkey>`,
`<ps4-companion>`, `<handshake-key>`, `<console-ip>`, `PS4-<redacted>` / `PS5-<redacted>`. Placeholders are consistent,
so passages that explain how one encoding derives from another still read correctly. Generic
protocol constants — discovery protocol versions, field offsets, the vendor binary's SHA-256 and its
RVAs — are **not** redacted: they are identical for every console and every user, and they are the
substance of the record. The unredacted working copy stays in the gitignored dirty room. This
matches the `NOTICE` commitment that no registration key, pairing record, session key, or device or
account identifier ships with Ripcord.
