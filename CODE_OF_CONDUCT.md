# Code of conduct

## The short version

Be decent. Assume good faith. Argue about the work, not the person.

Ripcord is a small project maintained in spare time, and its subject matter — reverse engineering a
protocol, with a legal position that depends on discipline — attracts strong opinions. Strong opinions are
welcome. Contempt is not.

## Expected behaviour

- Keep criticism specific and about the artefact: the code, the spec, the claim, the measurement.
- Say what you actually observed, and distinguish it from what you inferred. This project marks unconfirmed
  values `[X]` for exactly that reason; the same honesty is expected in discussion.
- Accept that "I was wrong" is a normal thing to say here. The repository's own history is full of
  corrections, several of them prominent, and that is a feature.
- Respect the clean-room rules in [`CONTRIBUTING.md`](CONTRIBUTING.md) even when you disagree with them.
  If you think a rule is wrong, argue it in an issue — do not quietly route around it.

## Unacceptable behaviour

- Personal attacks, harassment, or demeaning comments about anyone.
- Discrimination or derogatory remarks based on any personal characteristic.
- Publishing others' private information — including their console identifiers, account details, network
  addresses, or packet captures — without explicit permission.
- Sustained disruption: reopening settled decisions without new evidence, or arguing in bad faith.
- Pressuring a maintainer to accept material of uncertain provenance.

## Scope

This applies in the repository — issues, pull requests, discussions, commit messages and code review — and
anywhere someone is representing the project.

## Reporting

Report a problem privately through the repository's **Security** tab using
**Report a vulnerability**, which is a private channel to the maintainers and works for conduct reports
too. Say plainly that it is a conduct report so it is not triaged as a security issue.

For behaviour by the maintainer, or anything you would rather not send here, GitHub's own
[report abuse](https://github.com/contact/report-abuse) route is available and is not controlled by this
project.

## Enforcement

Reports are read and acted on. Responses range from a private word, through editing or removing the
offending contribution, to blocking an account — proportionate to what happened and whether it repeats.
This is a personal project without a moderation team, so expect a considered response rather than a fast
one.
